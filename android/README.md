# Android client

Open in Android Studio or build with a compatible JDK and Android SDK. Copy `web/` to `app/src/main/assets/web/` before building. Production must use HTTPS and disable cleartext traffic.


## Google features

Google identity integration kit and setup guide: [android/google-auth](google-auth/README.md). The kit currently documents and scaffolds native integration; native sign-in is not enabled until Android UI wiring and the backend mobile ID-token exchange endpoint are implemented and tested.
